# HyperLauncher 1.0.0

## Release highlights

- Consolidated home screen, app drawer, search, folders, hidden apps and dock customization.
- Global activity-level swipe recognition so gestures can begin over app tiles and other launcher content.
- Added Android system-bar inset handling to protect the clock, app drawer header and dock on Android 15+ edge-to-edge displays.
- Added app icon, dark theme and About/version screen.
- Set release version to 1.0.0 and added a dedicated release APK build/verification workflow.

## Compatibility notes

- Xiaomi-only privileged services and proprietary MIUI widgets are not bundled.
- The release APK is signed for local installation; it is not signed with a privately managed Play Store key.
