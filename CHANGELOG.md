# HyperLauncher 1.0.1

## HyperOS-inspired visual update

- Reworked the home clock card: removed generic 'YOUR SPACE' branding and settings gear.
- Automatically places common installed apps on the home screen and in the dock on first launch, so the home page is not blank. Existing user layouts are preserved.
- Changed default home and drawer grids to four columns.
- Added a horizontally scrolling category row based on categories present in the supplied Xiaomi launcher APK: Communication, Entertainment, Photography, Tools, Games, Travel, Finance & Business, Personalization, TV & Music and Video.
- Added category filtering in the app drawer.

## 1.0.0 release notes

## Release highlights

- Consolidated home screen, app drawer, search, folders, hidden apps and dock customization.
- Global activity-level swipe recognition so gestures can begin over app tiles and other launcher content.
- Added Android system-bar inset handling to protect the clock, app drawer header and dock on Android 15+ edge-to-edge displays.
- Added app icon, dark theme and About/version screen.
- Set release version to 1.0.0 and added a dedicated release APK build/verification workflow.

## Compatibility notes

- Xiaomi-only privileged services and proprietary MIUI widgets are not bundled.
- The release APK is signed for local installation; it is not signed with a privately managed Play Store key.
